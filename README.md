# 你说我猜（you-guess-me）

「你说我猜」小游戏，PWA 方案，用 Safari「添加到主屏幕」即可像原生 App 一样全屏使用。

**核心玩法**：开局倒数时摆好姿势作为基准，之后
- 屏幕**朝下压**（低头动作）→ **正确**，换下一个词
- 屏幕**翻起来**（抬头动作）→ **跳过**，换下一个词

方向可以在设置里对调；传感器不可用时自动降级为「点按屏幕左/右半屏」。

## 功能

- 9 个分类词库（日常生活 / 动物世界 / 成语天地 / 网络热词 / 演技比拼 / 随机题卡 / 吃货天堂 / 亲子乐园 / K歌之王），每局随机洗牌不重复
- 每局时长可选 60 / 120 / 180 / 240 / 300 秒
- 倾斜检测：以开局姿势为基准的相对角度判定，横握竖握、斜靠在桌上都成立；带冷却防连触
- 结算页：答对 / 跳过词列表；首页右上角「战绩」图标可查看历史对局表（日期 / 对局用时 / 正确数 / 跳过数），支持清空（存本机 localStorage）
- 设置：倾斜控制开关（关闭后纯点按玩）、倾斜灵敏度、方向对调、音效开关
- 屏幕常亮（iPadOS 16.4+ 自动生效）、切后台自动暂停、恢复时若旋转过设备自动重新校准
- Service Worker 全量预缓存，添加到主屏幕后**离线可玩**

## 本地试玩（桌面浏览器）

```bash
npm start        # http://localhost:3000
```

桌面没有传感器，会自动进入点按模式（左半屏跳过 / 右半屏正确），可用来调试词库和流程。


## iPad 安装步骤

1. 用 **Safari** 打开部署好的网址
2. 点分享按钮 → **添加到主屏幕**
3. 从主屏幕图标打开（此后是全屏独立 App，无浏览器地址栏）
4. 选分类点「开始」，弹出「"你比划我猜"想访问您的动作与方向」时点**允许**
5. 倒数 3 秒内把 iPad 摆到游玩姿势（正对猜词的人），校准完成即自动开局

> 首次打开需要联网加载一次并完成缓存，之后断网也能玩。

## 系统要求

- 动作传感器权限：iPadOS 13+
- 屏幕常亮（Wake Lock）：iPadOS 16.4+（旧系统请到 设置→显示与亮度→自动锁定 调成「永不」）
- 网页无法锁定横屏：游戏进行中若竖屏会显示「请横屏游玩」提示

## 自定义

- **改词/加词**：编辑 `js/words.js`，词与词之间用空格分隔；加新分类照抄一个对象（改 `id/name/desc/img`），首页九宫格自动多一格；首页分类卡片使用 `img/` 目录下的同名主题图（图片自带文字，加载失败时回退 emoji + 文字）
- **换「正确」音效**：用同名文件覆盖 `mp3/wo.mp3` 即可（答对时优先播放它，加载失败自动回退内置合成音）
- **换「跳过」音效**：用同名文件覆盖 `mp3/pass.mp3` 即可，回退逻辑同上
- **改图标**：改 `tools/gen-icons.js` 后运行 `npm run icons`
- **更新线上版本**：改动静态文件后把 `sw.js` 里的 `VERSION` 换个值（如 `v1.1.1`），客户端下次打开会自动更新缓存

## 目录结构

```
index.html            页面结构
css/style.css         样式
js/words.js           词库（9 分类）+ 首页主题图路径
js/tilt.js            倾斜检测（重力向量 + 基准校准 + 防连触）
js/audio.js           Web Audio 音效 + 自定义 mp3（mp3/wo.mp3 答对、mp3/pass.mp3 跳过）
js/app.js             游戏状态机 / 计时 / 结算 / 设置 / 战绩
img/                  首页分类主题图
mp3/                  自定义音效
sw.js                 Service Worker（离线缓存）
manifest.webmanifest  PWA 清单
icons/                应用图标（tools/gen-icons.js 生成）
serve.js              本地开发服务器
tools/gen-icons.js    图标生成脚本
```
