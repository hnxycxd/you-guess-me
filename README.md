# 你比划我猜（tilt-charades）

「你比我猜」聚会小游戏，PWA 方案，用 Safari「添加到主屏幕」即可像原生 App 一样全屏使用。

**核心玩法**：开局倒数时摆好姿势作为基准，之后
- 屏幕**朝下压**（低头动作）→ **正确**，换下一个词
- 屏幕**翻起来**（抬头动作）→ **跳过**，换下一个词

方向可以在设置里对调；传感器不可用时自动降级为「点按屏幕左/右半屏」。

## 功能

- 9 个分类词库（日常生活 / 动物世界 / 成语天地 / 网络热词 / 演技必拼 / 随机题卡 / 吃货开堂 / 亲子乐园 / K歌之王），每局随机洗牌不重复
- 每局时长可选 60 / 120 / 180 / 240 / 300 秒
- 倾斜检测：以开局姿势为基准的相对角度判定，横握竖握、斜靠在桌上都成立；带冷却防连触
- 结算页：答对 / 跳过词列表 + 历史战绩（存本机 localStorage）
- 设置：倾斜灵敏度、方向对调、音效开关、清除战绩
- 屏幕常亮（iPadOS 16.4+ 自动生效）、切后台自动暂停、恢复时若旋转过设备自动重新校准
- Service Worker 全量预缓存，添加到主屏幕后**离线可玩**

## 本地试玩（桌面浏览器）

```bash
npm start        # http://localhost:3000
```

桌面没有传感器，会自动进入点按模式（左半屏跳过 / 右半屏正确），可用来调试词库和流程。

## 部署（二选一，都是免费 HTTPS）

倾斜传感器要求 **HTTPS**，所以必须部署到线上，不能局域网 HTTP 直开。

**方式 A：Cloudflare Pages（国内访问较稳，推荐）**
1. 打开 dash.cloudflare.com → Workers & Pages → Create → Pages → **Upload assets**
2. 项目随便起名（如 `tilt-charades`），把本目录整个文件夹拖进去
3. Deploy，得到 `https://<项目名>.pages.dev`

也可以推到 GitHub 后在 Pages 里 Connect Git 仓库（构建命令留空，输出目录填 `/`）。

**方式 B：GitHub Pages**
1. 把代码推到 GitHub 仓库
2. 仓库 Settings → Pages → 选 main 分支根目录
3. 得到 `https://<用户名>.github.io/<仓库名>/`

## iPad 安装步骤

1. 用 **Safari** 打开部署好的网址
2. 点分享按钮 → **添加到主屏幕**
3. 从主屏幕图标打开（此后是全屏独立 App，无浏览器地址栏）
4. 选分类点「开始」，弹出「"你比划我猜"想访问您的动作与方向」时点**允许**
5. 倒数 3 秒内把 iPad 摆到游玩姿势（正对猜词的人），校准完成即自动开局

> 首次打开需要联网加载一次并完成缓存，之后断网也能玩。
> 若误点了「不允许」：设置 → Safari → 高级 → 网站数据，找到该站点删除后重试。

## 系统要求

- 动作传感器权限：iPadOS 13+
- 屏幕常亮（Wake Lock）：iPadOS 16.4+（旧系统请到 设置→显示与亮度→自动锁定 调成「永不」）
- 网页无法锁定横屏：游戏进行中若竖屏会显示「请横屏游玩」提示

## 自定义

- **改词/加词**：编辑 `js/words.js`，词与词之间用空格分隔；加新分类照抄一个对象（改 `id/name/desc/bg/emoji`），首页九宫格自动多一格
- **改图标**：改 `tools/gen-icons.js` 后运行 `npm run icons`
- **更新线上版本**：改动静态文件后把 `sw.js` 里的 `VERSION` 换个值（如 `v1.0.1`），客户端下次打开会自动更新缓存

## 目录结构

```
index.html            页面结构
css/style.css         样式
js/words.js           词库（9 分类）
js/tilt.js            倾斜检测（重力向量 + 基准校准 + 防连触）
js/audio.js           Web Audio 音效（无音频文件）
js/app.js             游戏状态机 / 计时 / 结算 / 设置
sw.js                 Service Worker（离线缓存）
manifest.webmanifest  PWA 清单
icons/                应用图标（tools/gen-icons.js 生成）
serve.js              本地开发服务器
tools/gen-icons.js    图标生成脚本
```
